# Google AI Mode DOM Keeper

A Chrome extension designed to virtualize long chat responses on the Google AI Studio / Google Search Threads page, preventing DOM overflow and keeping your browser smooth during long AI conversations.

<br />

## ⚠️ Important Disclaimer (As Is)

This extension was originally created for personal use. You are welcome to use it, but please be aware of the following conditions:  
* **Use at your own risk:** The extension is provided "as is", without any warranties or guarantees.
* **Memory Consumption:** The extension stores virtualized data directly in the **RAM (system memory)**. It does not actively monitor or limit memory usage. 
* **RAM Management:** On exceptionally large chats, it can consume a significant amount of RAM. If your system is low on memory, it may use up all available resources. **Please monitor your browser's memory usage manually.**
* **Initial Loading:** If a chat history is very large, the initial loading process might take some time to process and virtualize the DOM.
* **Bugs:** As an experimental tool, bugs may occur.

<br />

## 🛠️ Installation

### Installing from a ZIP Archive (Developer Mode)
If you downloaded this extension as an archive, follow these steps to install it in Google Chrome:  
1. Download and extract the `.zip` archive to a folder on your computer. You can find the latest version of the extension in the [Releases](https://github.com/AvenVaro/google-ai-mode-dom-keeper/releases/) section.
2. Open Google Chrome and navigate to `chrome://extensions/`.
3. In the top-right corner, enable the **Developer mode** toggle.
4. Click the **Load unpacked** button in the top-left corner.
5. Select the folder where you extracted the extension files.
